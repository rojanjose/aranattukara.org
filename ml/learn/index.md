**ഇവിടെ തുടങ്ങാം:** [അരണാട്ടുകര ഒറ്റനോട്ടത്തിൽ]({{ '/ml/at-a-glance/' | relative_url }}) — വാർഡുകൾ, ജനപ്രതിനിധികൾ, അയൽപ്രദേശങ്ങൾ, ജനസംഖ്യ, അതിർത്തി മാപ്പ്.

## വാക്കുകൾ

| വാക്ക് | അർത്ഥം |
|---|---|
| കര | വെള്ളത്തിൽ നിന്ന് ഉയർന്നുനിൽക്കുന്ന ഭൂമി |
| കോൾ | മഴക്കാലത്ത് വെള്ളം കയറുന്ന താഴ്ന്ന നെൽപ്പാടങ്ങൾ |
| പണ്ടികശാല | വ്യാപാരച്ചരക്കുകൾ സൂക്ഷിക്കുന്ന സംഭരണശാല |
| ചുങ്കം | ചരക്കിന്മേലുള്ള കരം; അത് പിരിക്കുന്ന സ്ഥലം |
| കടവ് | വള്ളങ്ങൾ അടുക്കുന്ന സ്ഥലം |
| തറവാട് | കുടുംബവീട് |
| കാവ് | വിശുദ്ധ വനം |
| പെരുന്നാൾ | പള്ളിയിലെ തിരുനാൾ |
